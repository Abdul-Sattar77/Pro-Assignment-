# Postman

API collections and environments for manual testing, kept in sync with the OpenAPI spec.

| Folder          | Contents                                                  |
| --------------- | --------------------------------------------------------- |
| `collections/`  | Postman collection(s), organized per module               |
| `environments/` | Environment files (local, staging) — no secrets committed |

See [`../docs/api/api-standards.md`](../docs/api/api-standards.md). Updating a Postman entry is part of the Definition of Done for any endpoint.
